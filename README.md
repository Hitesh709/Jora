# Jora

AI coding agent evolving into a controlled **AI Evolution OS**.

## Vision

Jora is designed to progress from an AI coding agent toward a production system that can understand requirements, plan software, coordinate agents, build and test applications, evaluate its own outputs, and safely propose and validate improvements to its own components.

## Core loop

Requirement → Plan → Build → Sandbox → Test → Evaluate → Deploy → Observe → Evolve

## Roadmap

The long-term program contains **10,000 production tasks across 20 phases**. The repository currently focuses on the first working vertical slice rather than generating disconnected scaffolding.

## Engineering principle

Self-evolution is controlled:

**Generate → Isolate → Test → Security Check → Benchmark → Compare → Approve → Version → Deploy → Monitor → Rollback**

No AI-generated change is automatically considered production-ready.
