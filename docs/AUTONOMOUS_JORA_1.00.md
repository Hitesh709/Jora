# Jora Autonomous Core — v0.55 to v1.00

Jora's target operating model is mission-driven autonomy: a durable mission selects the next roadmap work, executes it through the existing build/security/evaluation/CI/promotion/deployment gates, records evidence, learns from outcomes, and selects the next eligible work.

## Safety envelope
Autonomy never bypasses sandboxing, security gates, policy, evaluation, regression checks, CI, promotion, deployment health checks, audit, or rollback.

## Milestones
- 0.56–0.60: mission and roadmap control
- 0.61–0.65: reasoning/planning integration
- 0.66–0.70: specialist collaboration
- 0.71–0.75: knowledge/RAG integration
- 0.76–0.80: experience-driven learning
- 0.81–0.85: Code Master autonomous engineering
- 0.86–0.90: autonomous software delivery
- 0.91–0.95: evaluation/regression intelligence
- 0.96–0.99: governance/security hardening
- 1.00: autonomous core milestone

v1.00 is a milestone, not a claim that every long-term capability is complete. The 10,000-task roadmap remains the work backlog beyond it.
