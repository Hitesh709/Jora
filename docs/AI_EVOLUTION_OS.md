# Jora — AI Evolution OS

Jora is evolving from an AI coding agent into an AI-native software production and controlled self-evolution platform.

## Mission

Jora should eventually be able to:

1. Understand a product requirement.
2. Generate requirements and acceptance criteria.
3. Design architecture.
4. Decompose work into executable tasks.
5. Select and coordinate specialist agents.
6. Generate and modify software.
7. Execute code in an isolated sandbox.
8. Test and evaluate results.
9. Deploy approved changes.
10. Observe production behavior.
11. Identify measurable weaknesses.
12. Propose improvements.
13. Build candidate versions.
14. Benchmark candidates against a champion.
15. Promote or roll back candidates according to explicit governance.

## Controlled self-evolution

Self-improvement is deliberately implemented as:

**Generate → Isolate → Test → Security Check → Benchmark → Compare → Approve → Version → Deploy → Monitor → Rollback**

Jora must never treat an AI-generated change as automatically production-ready.

## Engineering rule

A task is complete only when its acceptance criteria are satisfied and evidence exists. Jora should maintain task state, tests, security results, benchmarks, commits, and rollback information.

## First production milestone

Build a working vertical slice before broad expansion:

**Requirement → Planner → Task Graph → Agent Runtime → Code Master → Sandbox → Tests → Evaluator → Versioned Result**

Once that loop is reliable, expand the Agent Factory and Evolution Engine.
